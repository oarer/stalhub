# Пользовательское соглашение

## 1. Общие положения

1.1. Настоящее Пользовательское соглашение (далее — «Соглашение») регулирует отношения между владельцем сервиса StalHub (далее — «Администрация») и пользователем сети Интернет (далее — «Пользователь»).

1.2. Использование сайта https://stalhub.tech означает полное и безоговорочное согласие Пользователя с условиями настоящего Соглашения.

1.3. В случае несогласия с условиями Соглашения Пользователь обязан прекратить использование Сервиса.

1.4. Сервис является Open Source-проектом и распространяется под лицензией GPL-3.0.

## 2. Термины

**Сервис** — веб-сайт StalHub и связанные с ним API, базы данных и программное обеспечение.

**Администрация** — владелец проекта и лица, уполномоченные на управление Сервисом.

**Пользователь** — любое лицо, использующее Сервис.

**Аккаунт** — учетная запись Пользователя, созданная через EXBO, Telegram или Discord.

## 3. Регистрация и авторизация

3.1. Регистрация осуществляется через сторонние сервисы:
- EXBO
- Telegram
- Discord

3.2. При авторизации Сервис может получать следующие данные:
- email (если предоставляется провайдером)
- имя пользователя
- аватар (если предоставляется провайдером)
- идентификатор аккаунта внешнего сервиса

3.3. Пользователь обязуется предоставлять достоверные данные, передаваемые через сторонние OAuth-сервисы (3.1).

## 4. Персональные данные

4.1. Сервис может обрабатывать следующие данные:
- email,
- имя / никнейм,
- аватар,
- JWT и refresh token (в хэшированном виде),
- IP-адрес,
- user-agent,
- cookies,
- данные local storage,
- дата и время входа.

4.2. Обработка данных осуществляется исключительно для функционирования Сервиса.

## 5. Права и обязанности пользователя

5.1. Пользователь имеет право:
- использовать функционал Сервиса;
- удалять свой аккаунт;
- обращаться в поддержку: support@stalhub.tech.

5.2. Пользователь обязуется:
- не нарушать законодательство РФ;
- не использовать Сервис во вред другим лицам;
- соблюдать правила сторонних сервисов (EXBO, Telegram, Discord).

## 6. Запрещенные действия

Пользователю запрещается:

6.1. Размещение и распространение:
- материалов, содержащих gore, snuff или порнографию;
- экстремистской, террористической или запрещенной символики;
- контента, разжигающего ненависть или дискриминацию.

6.2. Оскорбления, травля, унижение достоинства пользователей.

6.3. Создание мультиаккаунтов с целью обхода блокировок.

6.4. Попытки взлома, эксплуатации уязвимостей, обхода ограничений.

6.5. Нарушение правил сторонних сервисов, используемых для авторизации.

## 7. Блокировка и удаление аккаунта

7.1. Администрация вправе:
- временно ограничить доступ к аккаунту;
- заблокировать аккаунт;
- удалить аккаунт без возможности восстановления при серьезных нарушениях.

7.2. Основания для блокировки включают нарушение раздела 6 настоящего Соглашения.

## 8. Удаление данных

8.1. Пользователь может самостоятельно удалить свой аккаунт.

8.2. При удалении аккаунта все связанные с ним данные удаляются полностью, за исключением случаев, предусмотренных законодательством РФ.

## 9. API

9.1. Сервис предоставляет API.

9.2. API может быть изменено, ограничено или прекращено Администрацией без предварительного уведомления.

9.3. API не предназначено для гарантированного публичного коммерческого использования.

## 10. Open Source и лицензия

10.1. Исходный код Сервиса доступен по лицензии GPL-3.0:
https://github.com/oarer/stalhub

10.2. Форки проекта допускаются в рамках GPL-3.0.

10.3. Администрация не несет ответственности за сторонние форки.

10.4. Использование названия "StalHub" и визуального оформления с целью выдачи стороннего проекта за официальный запрещено.

## 11. Изменение условий

11.1. Администрация вправе изменять настоящее Соглашение.

11.2. При изменении условий Администрация обязана уведомить всех зарегистрированных пользователей.

11.3. Новая редакция вступает в силу с момента уведомления пользователей.

## 12. Заключительные положения

12.1. Настоящее Соглашение регулируется законодательством Российской Федерации.

12.2. Все споры решаются в соответствии с законодательством РФ.

12.3. Контакты Администрации:
- support@stalhub.tech
- https://stalhub.tech/about
