# Политика конфиденциальности

## 1. Общие положения

1.1. Настоящая Политика конфиденциальности (далее — «Политика») описывает, какие данные обрабатывает сервис StalHub (далее — «Сервис»), для чего они используются, как хранятся и как Пользователь может их удалить.

1.2. Использование сайта https://stalhub.dev означает согласие Пользователя с настоящей Политикой. В случае несогласия Пользователь обязан прекратить использование Сервиса.

1.3. Сервис является Open Source-проектом (подробнее — в документе [Terms](/legal/terms)). Настоящая Политика применяется к официальному инстансу на https://stalhub.dev. Администрация не несет ответственности за обработку данных сторонними форками проекта.

## 2. Какие данные мы собираем

2.1. Данные, получаемые от OAuth-провайдера при авторизации (предоставляются только в том объеме, в котором их передает провайдер):

- email (если предоставляется провайдером);
- имя пользователя / никнейм;
- аватар (если предоставляется провайдером);
- идентификатор аккаунта внешнего сервиса.

2.2. Данные, обрабатываемые для функционирования Сервиса:

- email;
- имя / никнейм;
- аватар;
- JWT и refresh token (в хэшированном виде);
- IP-адрес;
- user-agent;
- cookies;
- данные local storage;
- дата и время входа.

2.3. Пользователь обязуется предоставлять достоверные данные, передаваемые через сторонние OAuth-сервисы.

## 3. OAuth-провайдеры

3.1. Авторизация осуществляется через сторонние сервисы:

- EXBO
- Telegram
- Discord

3.2. При авторизации Сервис получает от выбранного провайдера только те данные, которые провайдер передает (см. раздел 2.1). Сервис не запрашивает доступ к данным, не требующимся для функционирования Сервиса.

3.3. На обработку данных на стороне OAuth-провайдера распространяются правила и политики конфиденциальности соответствующего провайдера. Пользователь обязуется соблюдать правила сторонних сервисов, используемых для авторизации.

## 4. Цели обработки

4.1. Обработка данных осуществляется исключительно для функционирования Сервиса, в том числе:

- создание и поддержание аккаунта Пользователя;
- аутентификация и поддержание сессии;
- обеспечение безопасности Сервиса;
- улучшение пользовательского опыта.

4.2. Данные не передаются третьим лицам, за исключением случаев, предусмотренных применимым законодательством (законодательством юрисдикции, в которой находится Пользователь).

## 5. Cookies и local storage

5.1. Сервис использует cookies для обеспечения корректной работы и улучшения пользовательского опыта.

5.2. Продолжая использовать Сервис, Пользователь дает согласие на обработку cookies в порядке, предусмотренном настоящим разделом.

5.3. Cookies подразделяются на:

- строго необходимые — обеспечивают работу Сервиса и не требуют отдельного согласия;
- аналитические и функциональные — используются для улучшения работы Сервиса.

5.4. Пользователь может в любой момент отключить cookies в настройках своего браузера. Однако это может привести к некорректной работе отдельных функций Сервиса.

5.5. Данные, хранимые в local storage браузера (например, настройки интерфейса), используются исключительно для функционирования Сервиса и не передаются третьим лицам. Для таких данных отдельное согласие не требуется.

## 6. Хранение и защита

6.1. JWT и refresh token хранятся в хэшированном виде.

6.2. Данные хранятся в течение срока существования аккаунта Пользователя и удаляются при его удалении, за исключением случаев, когда хранение данных требуется в соответствии с применимым законодательством.

6.3. Администрация принимает разумные меры для защиты данных от несанкционированного доступа, однако не может гарантировать абсолютную безопасность при передаче данных через сеть Интернет.

## 7. Удаление данных

7.1. Пользователь может самостоятельно удалить свой аккаунт.

7.2. При удалении аккаунта все связанные с ним данные удаляются полностью, за исключением случаев, когда хранение данных требуется в соответствии с применимым законодательством.

## 8. Права пользователя

8.1. Пользователь имеет право:

- использовать функционал Сервиса;
- удалять свой аккаунт и связанные с ним данные (раздел 7);

8.2. Права Пользователя, которые в соответствии с законодательством юрисдикции, в которой он находится, не могут быть ограничены соглашением, сохраняются в полном объеме (см. [Terms](/legal/terms)).
